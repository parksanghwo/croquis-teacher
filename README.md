# 무한 사진 캔버스

사진을 끌어다 놓고, 화살표로 잇고, 두 이미지를 50%씩 겹쳐 보고, 펜으로 그리는 웹 보드입니다.
프론트엔드(브라우저 화면)와 백엔드(Node.js 서버)로 나뉘어 있고, 작업 내용은 서버에 저장되므로 새로고침하거나 다른 브라우저로 열어도 그대로 남습니다.

## 실행하기

Node.js 20.11 이상이 필요합니다.

```bash
npm install
```

```bash
npm start
```

브라우저에서 http://localhost:3000 을 엽니다. 포트를 바꾸려면 `PORT=8080 npm start`처럼 실행하세요.
코드를 고치면서 쓸 때는 `npm run dev`로 실행하면 서버 파일이 바뀔 때마다 자동으로 다시 시작합니다.

## 폴더 구조

```
photo-canvas/
├── frontend/              브라우저에서 돌아가는 화면 (빌드 과정 없음)
│   ├── index.html         화면 뼈대: 보드, 도구 막대, 사용법, 그리기 화면, 전체화면 보기
│   ├── styles.css         색·글꼴 토큰과 모든 스타일 (밝은/어두운 테마)
│   └── js/
│       ├── app.js         보드 동작 전체: 이동·확대, 사진 배치, 노브, 화살표, 크롭, 그리기, 저장 동기화
│       ├── api.js         백엔드와 주고받는 요청 모음
│       └── strokes.js     펜 선 그리기와 크롭 계산 (화면·그리기 모드가 함께 씀)
├── backend/               Node.js + Express 서버
│   ├── server.js          API, 정적 파일 제공, 입력 검증
│   ├── store.js           보드 저장(JSON 파일)과 쓰지 않는 이미지 정리
│   └── compose.js         겹쳐 보기 이미지 합성 (sharp)
└── data/                  실행하면 생기는 저장 폴더 (백업은 이 폴더만 복사하면 됩니다)
    ├── board.json         사진 위치·크기·크롭·펜 선, 화살표, 화면 위치
    └── uploads/           올린 원본 이미지와 겹쳐 보기 이미지
```

## 역할 나누기

| 기능 | 프론트엔드 | 백엔드 |
|---|---|---|
| 사진 끌어다 놓기·붙여넣기·파일 선택 | 파일을 받아 서버로 올리고 보드에 배치 | 이미지 형식 확인, 크기(EXIF 회전 반영) 읽기, 저장 |
| 이동·크기 조절·크롭(Alt+드래그/휠) | 화면에서 바로 반영 | 바뀐 항목만 받아 저장 |
| 노브로 빈 캔버스 만들기, 화살표 연결 | 크기·비율 맞추기, 화살표 그리기 | 항목·화살표 저장 |
| 화살표 클릭 → 겹쳐 보기 | 요청 후 결과를 보드에 표시 | 두 항목을 보드에 보이는 그대로(크롭·확대·펜 선 포함) 그려서 50%씩 합성한 PNG 생성 |
| 빈 캔버스 검은 펜, 겹쳐 보기 빨간 펜 | 그리기 화면, 실행 취소, 필압 | 선 데이터 저장 |
| 삭제 | 화면에서 제거 | 항목·연결 화살표 삭제, 아무도 안 쓰는 이미지 파일 정리 |

저장은 자동입니다. 도구 막대 오른쪽 끝에 상태가 보입니다: **저장됨 / 저장 중… / 서버 연결 끊김 / 저장 실패**.
서버가 꺼져도 화면에서는 계속 작업할 수 있고, 서버가 다시 켜지면 3초 간격으로 다시 시도해 자동으로 저장합니다(페이지를 닫지 않은 경우).

## API

모든 경로는 `/api` 아래에 있고, 오류는 `{ "error": "한국어 설명" }` 형태로 돌려줍니다.

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/board` | 보드 전체: `{ camera, items, links }` |
| PUT | `/api/camera` | 화면 위치 `{ x, y, z }` 저장 |
| POST | `/api/images` | 이미지 업로드 (요청 본문 = 이미지 파일, `Content-Type: image/*`, 최대 40MB) → `{ id, url, width, height }` |
| PUT | `/api/items/:id` | 항목 저장 `{ x, y, w, h, order, image?, cover?, pos?, zoom?, strokes?, label? }` |
| DELETE | `/api/items/:id` | 항목 삭제 (연결된 화살표도 함께 삭제) |
| PUT | `/api/links/:id` | 화살표 저장 `{ from, to, side, overlay? }` |
| DELETE | `/api/links/:id` | 화살표 삭제 |
| POST | `/api/links/:id/overlay` | 겹쳐 보기 만들기/새로 고치기 → `{ item, link, created }` |

이미지 파일은 `/images/<파일명>`으로 제공됩니다.

## 알아 둘 점

- 한 사람이 쓰는 도구로 만들었습니다. 로그인이 없으므로, 인터넷에 공개하려면 앞단에 인증(예: 리버스 프록시의 기본 인증)을 붙이세요.
- 같은 보드를 두 브라우저에서 동시에 고치면 나중에 저장한 쪽이 이깁니다. 실시간 동시 편집은 아직 없습니다.
- 화살표 연결이 끊긴 사진은 1시간이 지나야 디스크에서 지워집니다(업로드 직후 저장 전에 지워지는 것을 막기 위해서입니다).
