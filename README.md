# 끄로뀌끼끼끼끼익

사진을 끌어다 놓고, 화살표로 잇고, 두 이미지를 50%씩 겹쳐 보고, 펜으로 그리는 웹 보드입니다.
프론트엔드(브라우저 화면)와 백엔드(Node.js 서버)로 나뉘어 있고, 작업 내용은 서버에 저장되므로 새로고침하거나 다른 브라우저로 열어도 그대로 남습니다.

## 실행하기

Node.js 20.11 이상이 필요합니다.

```bash
npm install
```

```bash
npm start
```

브라우저에서 http://localhost:3000 을 엽니다. 포트를 바꾸려면 `PORT=8080 npm start`처럼 실행하세요.
코드를 고치면서 쓸 때는 `npm run dev`로 실행하면 서버 파일이 바뀔 때마다 자동으로 다시 시작합니다.

## AI 선화 추출 켜기

노브로 사진과 크로키를 화살표로 이으면(또는 연결된 빈 캔버스에 크로키 사진을 넣으면) 바로 두 이미지를 겹친 "겹쳐 보기"가 생깁니다. 화살표를 클릭하면 겹쳐 보기를 다시 만들고 자동 맞춤으로 되돌립니다. 이을 때 크로키 사진은 종이 위 인물이 있는 곳을 찾아, 같은 비율로 자르면서도 머리부터 발까지 다 보이도록 크롭 위치를 정합니다(안 들어가면 조금 줄임). OpenAI API 키를 넣어 두면 겹치기 전에 이미지 모델로 선을 추출합니다.

- **화살표 출발 쪽 (참고 사진)**: 실사 사진 → 크로키 연습용 선화 (원본 윤곽을 그대로 트레이싱)
- **화살표 도착 쪽 (크로키 사진)**: 종이·그림자·노이즈를 지우고 연필선만 추출

`.env.example`을 `.env`로 복사하고 키를 넣은 뒤 서버를 다시 시작하세요.

```bash
cp .env.example .env
```

```
OPENAI_API_KEY=sk-...
OPENAI_IMAGE_MODEL=        # 비우면 gpt-image-2.6-flare
```

- 키는 서버에만 있고 브라우저로 보내지지 않습니다. 서버를 켜면 터미널에 "AI 선화 추출 켜짐"이 표시됩니다.
- 모델에는 원본 비율을 지키도록 흰 여백을 붙여 보내고(1:3~3:1, 긴 변 1536px), 돌아온 결과에서 여백을 잘라 원본과 같은 캔버스 크기로 되돌립니다. 흰 바탕은 투명으로 바꿔 검은 선만 남긴 PNG로 저장합니다.
- 추출 결과는 사진마다 저장해 두므로 같은 사진은 한 번만 모델에 보냅니다. 크롭·확대를 바꿔 겹쳐 보기가 다시 만들어질 때는 저장된 선화를 씁니다.
- 처음 추출은 사진마다 수십 초 걸릴 수 있습니다. 그동안 화살표가 움직이는 점선으로 바뀝니다.
- **불투명도**: 겹쳐 보기에서 사진에서 뽑은 선화는 30%, 크로키 선화는 50%로 흰 바탕 위에 겹칩니다. 겹쳐 보기를 **오른쪽 클릭**하면 사진 선화를 숨기고, 다시 오른쪽 클릭하면 보입니다(저장됨).
- **비교 (Enter)**: 겹쳐 보기를 선택하고 Enter를 누르면 사진 선화의 각 부분이 크로키 선과 얼마나 떨어져 있는지 재서, 크게 다른 부위(주변 영역의 선 중 40% 넘게 크로키 선에서 그림 크기의 약 0.8~2.5% 이상 떨어진 곳)는 빨갛게, 맞는 부분은 12% 정도로 더 흐리게 보여 줍니다. 크로키 층을 Alt+드래그/스크롤로 옮기면 다시 계산하고, Enter를 다시 누르면 꺼집니다. 계산은 브라우저에서 하며 켜짐 여부만 저장됩니다. AI로 선을 뽑은 겹쳐 보기에서만 동작합니다.
- **이전 버전의 겹쳐 보기**: 한 장짜리로 저장된 예전 겹쳐 보기는 페이지를 열 때 자동으로 두 층으로 다시 만들어집니다.
- **손으로 맞추기**: 겹쳐 보기는 (AI를 쓰든 안 쓰든) 참고 쪽과 크로키 쪽을 따로 된 두 층으로 보여 줍니다. 겹쳐 보기 틀과 사진에서 뽑은 선화는 움직이지 않습니다. 겹쳐 보기 위에서 **Alt+드래그**하면 크로키 선화가 움직이고, **Alt+스크롤**하면 포인터를 중심으로 크로키 선화의 크기가 바뀝니다(가로세로 같은 배율). 손으로 맞춘 값은 저장되고, 크롭을 바꿔 겹쳐 보기가 다시 만들어져도 유지됩니다. 화살표를 다시 클릭하면 자동 맞춤으로 돌아갑니다.
- 원본 크로키(보드의 사진)에서도 Alt+드래그로 틀 안 위치를, Alt+스크롤로 크기를 바꿀 수 있습니다. 틀보다 작게(20%까지) 줄일 수도 있습니다.
- 키가 없으면 지금처럼 원본을 그대로 50%씩 겹치고, 겹쳐 보기 이름에 "원본"이라고 표시됩니다.
- **자동 맞춤**: 겹치기 전에 두 선화에서 인물이 차지하는 영역(선 픽셀의 가장자리 1%를 뺀 범위)을 찾아, 도착 쪽 그림을 출발 쪽 인물과 크기·위치가 비슷하게 겹치도록 옮깁니다. 가로세로를 같은 배율로만 키우거나 줄이므로(0.5~2배) 그림의 비율은 바뀌지 않습니다. 출발 쪽(참고 선화)은 그대로 둡니다. 도착 쪽은 보드의 크롭 대신 그림 전체를 기준으로 맞추므로 머리나 발이 잘리지 않습니다. 두 쪽 모두 선일 때(AI 추출 결과나 빈 캔버스에 그린 그림)만 동작하고, 원본 사진끼리 겹칠 때는 하지 않습니다.
- 프롬프트 문구는 `backend/ai.js`의 `PROMPTS`에서 고칠 수 있습니다.

## 교정 기록 (숨은 표)

빨간 펜으로 교정하는 캔버스(겹쳐 보기, 또는 사진 위)마다 화면에 보이지 않는 표가 하나씩 붙어 있습니다.

| 그림 파일명 | 부위 | 교정 내용 | 오류 유형 | 반복 패턴 |

- 빨간 펜 선을 마지막으로 고친 뒤 **10초** 동안 그 캔버스를 다시 고치지 않으면 교정을 마친 것으로 보고, 크로키 선(연필처럼 회색)과 빨간 교정선을 한 장으로 그려 분석 모델(`OPENAI_MODEL`, 기본 gpt-6-luna)에 보냅니다. 돌아온 표의 행을 그 캔버스의 기록으로 저장합니다. 겹쳐 보기에서는 사진 선화를 빼고 보냅니다.
- 같은 캔버스를 다시 고치면 최신 상태로 다시 분석해 그 캔버스의 행을 바꿉니다. 바뀐 게 없으면 다시 보내지 않고, 빨간 선을 모두 지우면 그 캔버스의 행도 지웁니다. 실행 취소·다시 실행, 전체화면 그리기도 고친 것으로 칩니다.
- **그림 파일명**은 올릴 때의 원래 파일 이름입니다(겹쳐 보기는 크로키 사진의 이름). 이름이 없으면 "사진 ○○○"으로 적습니다.
- **반복 패턴**을 같은 말로 적도록, 지금까지 기록된 반복 패턴 표현을 함께 보냅니다.
- 표는 화면에 나오지 않습니다. `http://localhost:3000/api/reviews.csv`(엑셀에서 열 수 있는 CSV) 또는 `/api/reviews`(JSON)로 받아 볼 수 있고, `data/board.json`의 `reviews`에 저장됩니다. 캔버스를 지워도 기록은 남습니다.
- 프롬프트는 `backend/review.js`의 `REVIEW_PROMPT`에서 고칠 수 있습니다. API 키가 없으면 기록하지 않습니다.

## 겹쳐 보기 묶어서 공통 특징 보기

- **Shift+클릭**으로 겹쳐 보기를 여러 개 고른 뒤 Shift를 떼거나, 빈 곳을 마우스·펜슬로 **올가미처럼 둘러 그리면**(가운데가 올가미 안에 든 항목이 선택됨) 겹쳐 보기 2개 이상이 한 묶음이 됩니다.
- 묶은 겹쳐 보기 오른쪽에 **괄호 모양 곡선**이 그려지고, 그 옆에 **공통 특징이 원 안에** 나타납니다. 더 많은 그림에 나온 특징일수록 원이 큽니다. 원에 마우스를 올리면 오류 유형과 해당 그림 파일명이 보입니다.
- 공통 특징은 각 겹쳐 보기의 교정 기록 표(교정 내용·반복 패턴 포함)를 모아 분석 모델(`OPENAI_MODEL`, 기본 gpt-6-luna)이 서로 다른 그림 2장 이상에서 반복된 오류만 골라 만듭니다. 표현이 달라도 같은 잘못이면 한 묶음, 오차 방향이 반대면 따로, 같은 그림 안의 반복은 1장으로 셉니다(`backend/groups.js`의 `COMMON_PROMPT`). 원 안에는 묶인 겹쳐 보기 중 그 특징이 가장 잘 드러난 한 장에서 해당 부위를 잘라낸 이미지가 들어갑니다(모델이 고른 그림·부위를, 다시 모델이 그 겹쳐 보기 이미지에서 위치를 찾아 정사각형으로 자름). 원 **아래**에 반복된 오류 패턴과 그 밑 작은 글씨로 **다음 연습에 적합한 사진의 조건**이 나옵니다. 글자 높이를 재서 다음 원을 그 아래에 놓으므로 원과 글자가 겹치지 않습니다. API 키가 없으면 그림 전체가 들어갑니다.
- 더 큰 범위로 다시 묶으면 그 안에 든 작은 묶음은 새 묶음으로 바뀝니다. 일부만 겹치는 묶음끼리는 옆으로 나란히 놓입니다. 아직 기록되지 않은 교정은 먼저 기록합니다. API 키가 없으면 반복 패턴 문구가 같은 것끼리 묶습니다.
- 묶음에 든 겹쳐 보기의 교정이 다시 기록되면 공통 특징도 다시 계산됩니다. 겹쳐 보기를 옮기면 괄호와 원이 따라갑니다.
- **원을 클릭**하면 사진처럼 상하좌우 노브가 생깁니다. 노브를 끌어 사진·빈 캔버스에 놓으면 원에서 그쪽으로 화살표가 생기고(크기는 바꾸지 않음), 빈 곳에 놓거나 노브를 클릭하면 묶인 겹쳐 보기와 같은 크기의 빈 캔버스가 화살표로 이어져 생깁니다(다음 연습 사진을 넣는 자리).
- 괄호나 원을 클릭해 묶음을 선택하고 Delete를 누르면 묶음과 원에서 나간 화살표가 지워집니다(겹쳐 보기와 그 화살표가 가리키던 사진은 그대로).

## Pinterest에서 연습 사진 찾기

- 공통 특징 **원을 더블클릭**(아이패드는 두 번 탭)하면, 원 아래 적힌 "다음 연습 사진 조건"으로 Pinterest에서 연습 사진을 찾아 **최대 4장**을 원 옆에 2×2로 놓고 원에서 화살표로 잇습니다. 찾는 동안 원 테두리가 깜빡이는 점선이 됩니다.
- 순서: 분석 모델(`OPENAI_MODEL`, 기본 gpt-6-luna)이 웹 검색을 **pinterest.com으로 한정**해, 원의 "공통 오류 패턴 | 다음 연습 사진의 조건"을 표로 받아 머리부터 양발 끝까지 들어온 선명한 전신 실사 사진의 **개별 핀 링크**를 8개까지, 사진마다 **어떤 부분을 보고 연습하면 되는지 한 문장**과 함께 찾음(검색 결과·보드 링크 제외) → 서버가 각 핀 페이지의 미리보기 이미지(og:image)를 받아옴 → 모델이 사진을 직접 보고 같은 기준(전신·선명함·연습 조건 충족)에 맞는 사진만 고름 → 4장까지 보드에 놓음. 맞는 사진이 4장보다 적으면 그만큼만 놓습니다.
- 사진 아래에 그 한 문장이 작은 글씨로 나오고, 누르면 그 핀이 새 탭에서 열립니다. 프롬프트는 `backend/pins.js`의 `PIN_PROMPT`입니다.
- 서버는 Pinterest 주소(pinterest.*, pin.it, pinimg.com)만 열어 봅니다. 사진마다 원래 핀 주소가 함께 저장됩니다(`source`).
- 가져온 사진은 개인 연습 참고용으로만 쓰세요. 로그인이 필요하거나 미리보기 이미지가 없는 핀은 건너뜁니다.
- 프롬프트는 `backend/pins.js`에 있습니다. OpenAI API 키가 필요합니다.

## 아이패드에서 쓰기

평소 화면에는 아무 조작 도구도 없습니다. **겹쳐 보기 하나를 더블클릭**(아이패드는 손가락으로 두 번 탭)하면 그 캔버스가 **화면 가득** 펼쳐지고, 그때만 오른쪽 위 **눈 버튼**, **비교 버튼**(겹친 원 두 개), **← → 버튼**, 왼쪽 아래 **펜 굵기 슬라이더**가 나타납니다.

- 눈 버튼은 그 캔버스의 사진 선화만 켜고 끕니다.
- 비교 버튼(또는 Enter)은 크로키와 크게 다른 부위의 사진 선화를 빨갛게, 맞는 부분은 더 흐리게 보여 줍니다. 보드의 겹쳐 보기에서도 같이 바뀝니다.
- ← →(그리고 두·세 손가락 탭)은 그 캔버스에서 그린 펜 선만 되돌리고 다시 그립니다.
- 펜 굵기는 예외로, 한 번 바꾸면 모든 캔버스에 계속 적용됩니다(브라우저에 기억).
- Esc나 종이 바깥을 누르면 보드로 돌아가고 도구가 사라집니다. 빈 캔버스를 더블클릭해도 같은 전체화면(검은 펜, 눈·비교 버튼 없음)이 열리고, 사진의 더블클릭은 전체화면 보기입니다.

- **애플 펜슬로 보드에 바로 그리기**: 사진·겹쳐 보기 위에는 빨간 펜, 빈 캔버스 위에는 검은 펜. 필압이 반영됩니다. 손가락은 그리지 않고 사진 이동·화면 이동·핀치 확대에 쓰입니다. 펜슬로 빈 곳을 둘러 그리면 올가미 선택이 됩니다(겹쳐 보기 2개 이상이면 묶음).
- **두 손가락 탭**: 실행 취소, **세 손가락 탭**: 다시 실행 (그리기 화면 안에서도 동작)
- **빈 곳을 손가락으로 두 번 탭**(컴퓨터는 빈 곳 더블클릭, 또는 Shift+1)하면 모든 캔버스가 화면에 들어오게 됩니다. 페이지를 열었을 때 화면에 캔버스가 하나도 없으면(다른 크기의 화면에서 저장된 위치 등) 자동으로 전체 보기를 합니다.
- 컴퓨터와 같은 와이파이에서 아이패드 사파리로 `http://컴퓨터IP:3000`을 엽니다.
- 컴퓨터에서는 지금까지의 단축키(Ctrl+Z/Ctrl+Shift+Z 포함)와 더블클릭 그리기 화면이 그대로 동작합니다. 사진 추가는 끌어다 놓기·붙여넣기로 합니다.

## 역할 나누기

| 기능 | 프론트엔드 | 백엔드 |
|---|---|---|
| 사진 끌어다 놓기·붙여넣기·파일 선택 | 파일을 받아 서버로 올리고 보드에 배치 | 이미지 형식 확인, 크기(EXIF 회전 반영) 읽기, 저장 |
| 이동·크기 조절·크롭(Alt+드래그/휠) | 화면에서 바로 반영 | 바뀐 항목만 받아 저장 |
| 노브로 빈 캔버스 만들기, 화살표 연결 | 크기·비율 맞추기, 화살표 그리기 | 항목·화살표 저장 |
| 화살표 클릭 → 겹쳐 보기 | 요청 후 진행 표시, 결과를 보드에 표시 | 출발 사진은 선화, 도착 크로키는 연필선으로 AI 추출(키가 있을 때) → 보드에 보이는 그대로(크롭·확대·펜 선 포함) 그려서 50%씩 합성한 PNG 생성 |
| 빈 캔버스 검은 펜, 겹쳐 보기 빨간 펜 | 그리기 화면, 실행 취소, 필압 | 선 데이터 저장 |
| 삭제 | 화면에서 제거 | 항목·연결 화살표 삭제, 아무도 안 쓰는 이미지 파일 정리 |

저장은 자동입니다. 도구 막대 오른쪽 끝에 상태가 보입니다: **저장됨 / 저장 중… / 서버 연결 끊김 / 저장 실패**.
서버가 꺼져도 화면에서는 계속 작업할 수 있고, 서버가 다시 켜지면 3초 간격으로 다시 시도해 자동으로 저장합니다(페이지를 닫지 않은 경우).

## API

모든 경로는 `/api` 아래에 있고, 오류는 `{ "error": "한국어 설명" }` 형태로 돌려줍니다.

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/board` | 보드 전체: `{ camera, items, links }` |
| GET | `/api/config` | AI 선화 추출 사용 여부: `{ ai, imageModel }` |
| PUT | `/api/camera` | 화면 위치 `{ x, y, z }` 저장 |
| POST | `/api/images` | 이미지 업로드 (요청 본문 = 이미지 파일, `Content-Type: image/*`, 최대 40MB) → `{ id, url, width, height }` |
| PUT | `/api/items/:id` | 항목 저장 `{ x, y, w, h, order, image?, cover?, pos?, zoom?, strokes?, label? }` |
| DELETE | `/api/items/:id` | 항목 삭제 (연결된 화살표도 함께 삭제) |
| PUT | `/api/links/:id` | 화살표 저장 `{ from, to, side, overlay? }` |
| DELETE | `/api/links/:id` | 화살표 삭제 |
| POST | `/api/links/:id/overlay` | 겹쳐 보기 만들기/새로 고치기 (AI 추출 포함) → `{ item, link, created, ai }`. 모델 오류는 502 |

이미지 파일은 `/images/<파일명>`으로 제공됩니다.

## 알아 둘 점

- 한 사람이 쓰는 도구로 만들었습니다. 로그인이 없으므로, 인터넷에 공개하려면 앞단에 인증(예: 리버스 프록시의 기본 인증)을 붙이세요.
- 같은 보드를 두 브라우저에서 동시에 고치면 나중에 저장한 쪽이 이깁니다. 실시간 동시 편집은 아직 없습니다.
- 화살표 연결이 끊긴 사진은 1시간이 지나야 디스크에서 지워집니다(업로드 직후 저장 전에 지워지는 것을 막기 위해서입니다).
