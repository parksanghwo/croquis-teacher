# 크로키 선생님

참고 사진과 내 크로키를 올리면, 사진에서 기준 선화를 따고 OpenAI 모델이 내 그림 위에 빨간 펜으로 고칠 곳을 짚어 주는 웹 앱입니다.

처음부터 끝까지 **책상 캔버스 한 화면**에서 해요.

1. **올리기** — 파일을 화면에 끌어다 놓거나(놓은 자리에 카드가 생겨요), 빈 곳을 클릭해서 **파일 업로드**(또는 왼쪽 위 **올리기**, 단축키 U)
   - 업로드 창: 파일 선택(여러 장) · 끌어다 놓기 · 휴대폰 QR (창을 연 채로 여러 장 보낼 수 있어요) · Ctrl/⌘+V 붙여넣기
   - 올린 이미지는 일단 같은 카드로 놓이고, 그다음 **사진인지 그림인지 판별**해요. 사진은 기준 선화를 따고, 그림은 연필선만 남겨요.
     잘못 판별됐으면 카드 이름표의 **그림이에요/사진이에요**, 지우려면 **빼기**
2. **연결 = 첨삭 시작** — 사진 카드에서 그림 카드로 마우스를 끌면 빨간 화살표로 이어지고, 바로 그 둘로 첨삭을 시작해요
   - 사진 카드 오른쪽 가장자리의 빨간 점을 끌어도 돼요. 화살표 가운데에서 **↻ 다시 첨삭**, **✕ 연결 끊기**
   - 사진·그림을 여러 장 올려 두고 쌍마다 따로 연결할 수 있어요 (그림 하나엔 사진 하나)
   - 위쪽 **첨삭 설정**에서 연습 시간·중점·비교 옵션
3. **사진 오른쪽 클릭 = 트레이싱 켜기/끄기** — 사진 위에 사진에서 딴 기준 선화를 겹쳐 보여요
   - 트레이싱을 켠 사진(첨삭이 끝난 것) 위를 드래그하면 올가미로 고르고, 고른 부분을 연결된 그림 위로 끌어 놓으면 그 부분만 따로 첨삭
4. **첨삭 결과** — 그림 위 빨간 교정선·파란 축선과 손글씨 메모
   - 빈 곳 드래그·휠로 이동, Ctrl/⌘+휠로 확대. 1.5배 이상 확대하면 메모 상세 설명(관찰·수정)이 드러나요
   - 카드 이름표를 잡고 끌어서 옮기기
   - 메모 클릭 = 확대/복귀, 오른쪽 클릭 = 빨간 선 켜기/끄기, Delete = 지우기, Ctrl+Z / Ctrl+Shift+Z = 되돌리기/다시 하기
   - 아래 도구 막대: 이동/손(V/H, 스페이스 누른 채 드래그), 빨간 선 표시, 교정선 투명도, 확대·축소·전체(0)
   - 오른쪽 위 **노트 정리** 서랍: 오답노트(관찰·원인·수정·다음 규칙)
   - 시스템 다크 모드를 따라가요 (종이는 흰색 그대로)
