# 크로키 선생님

참고 사진과 내 크로키를 올리면, 사진에서 기준 선화를 따고 OpenAI 모델이 내 그림 위에 빨간 펜으로 고칠 곳을 짚어 주는 웹 앱입니다.

1. **업로드 & 설정** — 사진 선택·끌어다 놓기·붙여넣기(Ctrl/⌘+V, 마우스를 올린 칸 우선)·휴대폰 QR 업로드. 원본 사진(자동 트레이싱으로 기준 선화 생성, 직접 그린 선화로 교체 가능), 내 크로키(종이 그림자 자동 보정), 연습 시간·중점·비교 옵션
2. **오버랩 첨삭** — 기준 선화/원본 사진 토글, 내 크로키 위 빨간 수정선과 메모. 드래그로 이동, 확대(버튼, Ctrl/⌘+휠, 메모 클릭)하면 상세 설명이 나타나고, 메모를 오른쪽 클릭하면 해당 수정선을 켜고 끔.
   왼쪽 기준 선화 위를 드래그해 올가미로 고르고, 고른 조각을 내 크로키 위에 끌어다 놓으면 그 부위만 따로 첨삭해 "(선택)" 메모로 추가돼요
3. **노트 정리** — 공책 형태 요약. 항목을 골라 Delete로 지우기, 되돌리기

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 열고, 오른쪽 위 **API 키** 버튼으로 OpenAI API 키를 입력하세요. 기본 모델은 `gpt-6-luna`이고, 같은 창에서 바꿀 수 있어요.
키를 매번 넣기 싫으면 `.env.example`을 `.env`로 복사하고 `VITE_OPENAI_API_KEY=sk-...`를 채운 뒤 `npm run dev`를 다시 실행하세요.
`.env`는 git에 올라가지 않고, **개발 서버(`npm run dev`)에서만** 읽어요. `npm run build` 결과물에는 키가 들어가지 않으니, 배포한 화면에서는 창에 직접 입력해야 해요. 창에 입력한 키가 `.env`보다 우선해요.

창에 입력한 키는 이 브라우저의 localStorage에만 저장되고("이 기기에 저장" 해제 시 새로고침하면 사라짐), 요청은 브라우저에서 OpenAI API로 바로 전송됩니다. 개인용 로컬 앱을 전제로 한 방식이니, 여러 사람이 쓰는 서비스로 배포한다면 키를 서버 쪽으로 옮기세요.

## 휴대폰으로 올리기 (QR)

각 칸의 **휴대폰으로** 버튼을 누르면 QR 코드가 떠요. 휴대폰 카메라로 찍으면 열리는 페이지에서 사진을 찍거나 고르면 PC의 그 칸에 바로 들어가요.

- PC와 휴대폰이 **같은 와이파이**에 있어야 해요.
- `npm run dev`(또는 `npm run preview`)로 실행했을 때만 돼요. 개발 서버가 사진을 잠깐 받아 PC 화면에 넘겨줘요 (`server/phone-upload.ts`).
- 그래서 개발 서버가 같은 네트워크의 다른 기기에서도 열리도록 설정돼 있어요(`vite.config.ts`의 `host: true`). 카페 같은 공용 와이파이에서는 같은 네트워크의 다른 사람도 이 앱 화면에 접속할 수 있으니 주의하세요.
- QR 주소에는 추측할 수 없는 일회용 토큰이 들어가고, 받은 사진은 메모리에만 있다가 PC가 가져가면 지워져요. 창을 닫거나 15분이 지나면 QR은 만료돼요.
- QR이 안 열리면 창의 주소 목록에서 다른 주소를 골라 보세요. 그래도 안 되면 PC 방화벽이 5173 포트를 막고 있을 수 있어요.

## 구조

- `src/lib/image.ts` — 이미지 축소, 소벨 에지 기반 선화 추출, 종이 보정, 잉크 영역 자동 정렬(크롭)
- `src/lib/ai.ts` — OpenAI Responses API 호출 (`gpt-6-luna`, 구조화 출력으로 항목별 좌표와 수정선 폴리라인을 받음)
- `src/screens/` — 세 화면 (`Upload`, `Compare`, `Report`)
- `src/styles.css` — 디자인 토큰(색·글꼴)과 공통 컴포넌트 스타일
