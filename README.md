# 크로키 선생님

참고 사진과 내 크로키를 올리면, 사진에서 기준 선화를 따고 OpenAI 모델이 내 그림 위에 빨간 펜으로 고칠 곳을 짚어 주는 웹 앱입니다.

1. **업로드 & 설정** — 사진 선택·끌어다 놓기·붙여넣기(Ctrl/⌘+V, 마우스를 올린 칸 우선)·휴대폰 QR 업로드. 연습 시간, 중점, 비교 옵션
2. **첨삭 캔버스** — 끝없이 넓은 책상 위에 원본 사진·기준 선화·내 크로키 종이를 펼쳐 놓은 화면
   - 빈 곳 드래그·휠로 이동, Ctrl/⌘+휠로 확대. 1.5배 이상 확대하면 메모 상세 설명(관찰·수정)이 드러나요
   - 카드 이름표를 잡고 끌어서 옮기기 (사진과 기준 선화는 함께 움직여요)
   - 기준 선화 위를 드래그해 올가미로 고르고, 내 크로키 위로 끌어다 놓으면 그 부분만 AI가 첨삭
   - 메모 클릭 = 확대/복귀, 오른쪽 클릭 = 빨간 선 켜기/끄기, Delete = 지우기, Ctrl+Z / Ctrl+Shift+Z = 되돌리기/다시 하기
   - 아래 도구 막대: 이동/손(V/H, 스페이스 누른 채 드래그), 사진·기준 선화·빨간 선 표시, 교정선 투명도, 확대·축소·전체(0)
   - 오른쪽 위 **노트 정리** 서랍: 오답노트(관찰·원인·수정·다음 규칙)
   - 시스템 다크 모드를 따라가요 (종이는 흰색 그대로)

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 열고, 오른쪽 위 **API 키** 버튼으로 OpenAI API 키를 입력하세요. 기본 모델은 `gpt-6-luna`이고, 같은 창에서 바꿀 수 있어요.
키를 매번 넣기 싫으면 `.env.example`을 `.env`로 복사하고 `VITE_OPENAI_API_KEY=sk-...`를 채운 뒤 `npm run dev`를 다시 실행하세요.
`.env`는 git에 올라가지 않고, **개발 서버(`npm run dev`)에서만** 읽어요. `npm run build` 결과물에는 키가 들어가지 않으니, 배포한 화면에서는 창에 직접 입력해야 해요. 창에 입력한 키가 `.env`보다 우선해요.

창에 입력한 키는 이 브라우저의 localStorage에만 저장되고("이 기기에 저장" 해제 시 새로고침하면 사라짐), 요청은 브라우저에서 OpenAI API로 바로 전송됩니다. 개인용 로컬 앱을 전제로 한 방식이니, 여러 사람이 쓰는 서비스로 배포한다면 키를 서버 쪽으로 옮기세요.

## AI 프롬프트

프롬프트는 `src/lib/prompts.ts` 한 파일에 모여 있어요. 문구를 바꾸려면 이 파일만 고치면 돼요.

1. **선화 추출** (`LINE_ART_PROMPT`) — 원본 사진 → 크로키 연습용 기준 선화. 이미지 모델(기본 `gpt-image-2`)
2. **연필선 추출** (`PENCIL_PROMPT`) — 크로키 사진 → 연필선만. 이미지 모델
3. **첨삭** (`CRITIQUE_PROMPT`) — 기준 선화 A와 학생 크로키 B 비교. 첨삭 모델(기본 `gpt-6-luna`)

- 1·2번은 원본 비율 그대로(16의 배수 크기) 요청하고, 결과를 원본과 같은 캔버스 크기로 맞춰요. 투명 배경 버전은 앱이 흰 배경 선화에서 만들어요.
- 업로드 화면의 "AI로 선화 추출"을 끄면 1·2번 대신 브라우저 자동 트레이싱(무료·즉시)을 써요. AI 호출이 실패하거나 API 키가 없을 때도 자동 트레이싱으로 대신해요.
- 3번은 모델이 이미지를 직접 그리지 않고 교정선 좌표(빨간 교정선·파란 축/방향선·흐리게 할 기존 선)와 오답노트(관찰·원인·수정·다음 규칙)를 돌려주면, 앱이 비교 화면·교정선 켜기/끄기·투명도·확대를 그려요.
- 사진 1장, 크로키 1장마다 이미지 모델이 한 번씩 호출돼서 시간(수십 초)과 비용이 들어요.

## 휴대폰으로 올리기 (QR)

각 칸의 **휴대폰으로** 버튼을 누르면 QR 코드가 떠요. 휴대폰 카메라로 찍으면 열리는 페이지에서 사진을 찍거나 고르면 PC의 그 칸에 바로 들어가요.

- PC와 휴대폰이 **같은 와이파이**에 있어야 해요.
- `npm run dev`(또는 `npm run preview`)로 실행했을 때만 돼요. 개발 서버가 사진을 잠깐 받아 PC 화면에 넘겨줘요 (`server/phone-upload.ts`).
- 그래서 개발 서버가 같은 네트워크의 다른 기기에서도 열리도록 설정돼 있어요(`vite.config.ts`의 `host: true`). 카페 같은 공용 와이파이에서는 같은 네트워크의 다른 사람도 이 앱 화면에 접속할 수 있으니 주의하세요.
- QR 주소에는 추측할 수 없는 일회용 토큰이 들어가고, 받은 사진은 메모리에만 있다가 PC가 가져가면 지워져요. 창을 닫거나 15분이 지나면 QR은 만료돼요.
- QR이 안 열리면 창의 주소 목록에서 다른 주소를 골라 보세요. 그래도 안 되면 PC 방화벽이 5173 포트를 막고 있을 수 있어요.

## 구조

- `src/lib/image.ts` — 이미지 축소, 소벨 에지 기반 선화 추출, 종이 보정, 잉크 영역 자동 정렬(크롭)
- `src/lib/prompts.ts` — 프롬프트 3개
- `src/lib/ai.ts` — OpenAI 호출 (선화 추출: Images API, 첨삭: Responses API + 구조화 출력)
- `src/screens/` — `Upload`(업로드·설정), `Workspace`(첨삭 캔버스)
- `src/styles.css` — 디자인 토큰(색·글꼴)과 공통 컴포넌트 스타일
