# 크로키 선생님

참고 사진과 내 크로키를 올리면, 사진에서 기준 선화를 따고 Claude가 내 그림 위에 빨간 펜으로 고칠 곳을 짚어 주는 웹 앱입니다.

1. **업로드 & 설정** — 원본 사진(자동 트레이싱으로 기준 선화 생성, 직접 그린 선화로 교체 가능), 내 크로키(종이 그림자 자동 보정), 연습 시간·중점·비교 옵션
2. **오버랩 첨삭** — 기준 선화/원본 사진 토글, 내 크로키 위 빨간 수정선과 메모. 드래그로 이동, 확대(버튼, Ctrl/⌘+휠, 메모 클릭)하면 상세 설명이 나타나고, 메모를 오른쪽 클릭하면 해당 수정선을 켜고 끔
3. **노트 정리** — 공책 형태 요약. 항목을 골라 Delete로 지우기, 되돌리기

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 열고, 오른쪽 위 **API 키** 버튼으로 Anthropic API 키를 입력하세요.
키는 이 브라우저의 localStorage에만 저장되고("이 기기에 저장" 해제 시 새로고침하면 사라짐), 요청은 브라우저에서 Anthropic API로 바로 전송됩니다. 개인용 로컬 앱을 전제로 한 방식이니, 여러 사람이 쓰는 서비스로 배포한다면 키를 서버 쪽으로 옮기세요.

## 구조

- `src/lib/image.ts` — 이미지 축소, 소벨 에지 기반 선화 추출, 종이 보정, 잉크 영역 자동 정렬(크롭)
- `src/lib/claude.ts` — Claude 호출 (`claude-opus-5-5`, 구조화 출력으로 항목별 좌표와 수정선 폴리라인을 받음, 거절 시 서버측 폴백)
- `src/screens/` — 세 화면 (`Upload`, `Compare`, `Report`)
- `src/styles.css` — 디자인 토큰(색·글꼴)과 공통 컴포넌트 스타일
